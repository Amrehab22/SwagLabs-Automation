# Swag Labs Automation

## Project Overview

This project is an automation framework for testing the Swag Labs
website using Selenium WebDriver and TestNG.

## Technologies

- Java
- Selenium WebDriver
- TestNG
- Maven
- Gson
- Page Object Model (POM)
- Data-Driven Testing
- Git & GitHub

## Test Scenarios

### Login Tests

1. Verify Successful Login
2. Verify Invalid Login
3. Verify Login Without Password

### Inventory Tests

1. Verify Page Title
2. Verify Cart Icon
3. Verify Six Products

testng.xml
